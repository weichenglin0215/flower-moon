## 結算公式

```
最終得分 = ( 遊戲中累計分 + base + 剩餘紅心 × heart + 剩餘秒數 × time ) × 難度倍率
難度倍率：小學 1、中學 2、高中 3、大學 4、研究所 5
```

## 三個推算前提（請務必先讀）

1. **一律假設完美通關**：紅心全滿、該拿的分都拿到。實際遊玩會低於此值，本表是**上限**不是期望值。
2. **「剩餘秒數」是最大變數**，同一款遊戲玩家快慢差幾倍，分數就差幾倍。因此下方給三種情境而非單一數字。
3. **「遊戲中累計分」的觸發次數是推估的**，每列都標了信心等級：
   - **高**：觸發次數可由設定值直接算出
   - **中**：觸發次數與題目長度相關，已用實際抽樣的詩句長度估算（每個難度抽 10 組題目取平均）
   - **低**：觸發次數取決於玩家操作（連鎖、combo、路徑），僅取保守下限
