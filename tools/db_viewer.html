怎麼用
  1. 第一次切到這一頁會自動查「30 天前到今天」的意見。要看別的時間、對象（系統面／某款遊戲）、關鍵字，在「查詢條件」改完按「查詢」。時間用這台電腦的時區，「到」那一天整天都算。
  2. 「對象」＝系統面：漢堡選單「關於花月」右邊的「提意見」寫的，是介面、功能、操作這類全面性的意見；「對象」＝某款遊戲：那款遊戲結算彈窗的「提意見」寫的。
  3. 只想貼「對象與意見」給 Claude：勾「只顯示 對象、意見內容」。不想貼的列，把最左邊的勾勾取消。
  4. 按「複製」，到 Claude 的輸入框貼上。每一列一行、欄位用 Tab 隔開；意見裡的換行會變成「 ⏎ 」，這樣一則意見不會斷成好幾行。
  5. 貼完按「把目前結果的最大 id 記為已處理」；下次按「從 id N 開始查」，就只會看到新的意見。（記在這個瀏覽器裡。）
  6. 這一頁只能「讀」：用的是花月本來就公開的 publishable key，只讀公開檢視表 player_feedback_public（不含玩家內部 id），不能新增、修改或刪除任何東西。
  7. 出現「資料庫還沒有玩家意見…」代表還沒執行 note/玩家意見_SQL草案.sql：到 Supabase 的 SQL Editor 執行後再查詢。
